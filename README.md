# MoveIn Match

MoveIn Match is a simple roommate compatibility app for college students. Pick
your sleep schedule, cleanliness preference, and housing budget to see which
sample roommate profiles are the best fit.

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS

## Run the project

Install the packages:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## How matching works

The app compares your preferences with four sample roommate profiles. Sleep
schedule and cleanliness are worth 35 points each, and housing budget is worth
30 points. Exact matches receive the most points, while similar preferences can
still receive partial credit.
